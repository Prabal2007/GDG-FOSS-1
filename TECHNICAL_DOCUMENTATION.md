## The Hook: Why I Chose This Stack

Mobile apps are used by everyone, and building App requires a mix of Creativity, Innovation and Deep Understanding. I chose Android development with Kotlin and Firebase because It allows me to create Real-World Apps quickly.

## Under the Hood: How it Works

* **Kotlin**: A modern & new language that is recommended by Google in development of an App and it reduces code in comparison to Java.
* **XML Layouts**: It defines the UI structure of App, which is linked to Kotlin file code.
* **Firebase**: I have little details, like Firebase is used for Authentication like login with gmail account, and provides services like Realtime Database.
* **Gradle**: Handles dependencies required in Project like if a feature is to used in app then corresponding dependencies has to be added, andd Also handles build configurations.

## The Trade-offs: Pros and Cons

**Pros:**
* Development became easy with Firebase(specially in backend part)
* Kotlin code is easily readable and looks similar like mix of python and java(My experience).

**Cons:**
* Firebase can become costly when more users and more big data is present
* XML layouts will have redundant tags which will make it difficult to resolve
